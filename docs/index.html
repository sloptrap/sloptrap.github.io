SlopTrap Documentation

Reference for building, running, and integrating SlopTrap across the interactive terminal workspace, autonomous crawler, WebAssembly rule engine, and HTTP verification server.

1. Installation & prerequisites

  • Go 1.24+ — Uses pure-Go SQLite (modernc.org/sqlite) and pure-Go WebAssembly interpretation (wazero); no CGO toolchain required.
  • Optional — ffmpeg: Enables 45-second EBU R128 loudness range (LRA) and -65dBFS digital dead-air acoustic TTS probing (a in TUI or --audio on CLI).
  • Optional — mpv & gh: Direct playback of newest/oldest channel uploads (o / O) and formatted GitHub issue submission to Override92/AiSList.
  • Optional — Local AiSList checkout: Auto-detected at ./AiSList or ../AiSList (or specified via --aislist /path/to/AiSList) for offline stem-sibling matching against 70,000+ community entries.
git clone git@github.com:sloptrap/sloptrap.git
cd sloptrap
go build -o sloptrap ./cmd/sloptrap

# Inspect CLI flags
./sloptrap -h
Local storage paths: Scanned channel reports and review/whitelist states are stored in ~/.local/share/sloptrap/sloptrap.db (override with --db). Local WASM rule bundles load from ~/.local/share/sloptrap/rules/*.strule.

2. Terminal UI guide

Running ./sloptrap with no flags launches the interactive Bubble Tea interface. Pass --listen 0.0.0.0:8787 to serve the HTTP verification API concurrently and inspect incoming client scans in real time. 

# Launch standalone TUI
./sloptrap

# Launch TUI + HTTP API server on port 8787 + initial targets
./sloptrap --listen 0.0.0.0:8787 "@UntoldTruths-x8z,@3blue1brown"

3. Headless CLI & crawler modes

# Headless forensic scan (text report on stdout)
./sloptrap --headless --scan "@bygonephilosophy,@veritasium"

# Headless scan with 45s ffmpeg audio analysis + structured JSON output
./sloptrap --headless --audio --json --scan "https://www.youtube.com/watch?v=dQw4w9WgXcQ"

# Crawl 500 unlisted channels and export AiSList-compatible text lists
./sloptrap --crawl 500 --export ./exports

# Export existing SQLite detections without network scanning
./sloptrap --export ./exports

4. AiSList reporting & submission identity

High-confidence detections not yet present in AiSList can be submitted automatically to POST https://api.aisloplist.com under three identity modes:

  • Anonymous (--report-as=anonymous) — Sends "username": "Anonymous" with no account identifier.
  • Custom Username (--report-as=custom --username=...) — Credits reports to an explicit handle.
  • Client Account Callback (--report-as=youtube) — Queries a connected media client's GET /api/v1/account callback endpoint at report time, falling back to Anonymous if unavailable.

5. HTTP server API reference (--serve / --listen)

Endpoint Description
GET /api/v1/health Returns service status, SQLite scan/block/warn/whitelist counts, and loaded AiSList counts.
POST /api/v1/check Batched channel/video verification. Returns cached AiSList + SQLite verdicts immediately and queues singleflight live scans when scan_unknown: true.
POST /api/v1/whitelist Marks or unmarks a channel as whitelisted in SQLite.
GET /lists/blocklist.txt
GET /lists/warnlist.txt		 Plain-text AiSList-compatible channel lists generated from SQLite verdicts.
GET /lists/leaderboard.json
GET /lists/bundles/<id>.strule		 Local LAN mirror of leaderboard metadata and signed .strule WebAssembly bundles.
