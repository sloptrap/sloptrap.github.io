Documentation & Library SDK

Integrate SlopTrap into your own application in two ways: as a zero-network static rule library, or with drop-in UI sections providing rule toggling, Verified provenance filtering, site-specific updates, and opt-in Anonymous rule rankings.

1. Library & UI integration

Mode A — Static rule set (headless, zero network)

Ideal for backend services, moderation pipelines, mobile/TV apps, or offline tools that want deterministic .strule evaluation without external network calls or UI state. 

// Go — pkg/sloptrap (built-in official verified rules or embed.FS)
import "sloptrap/pkg/sloptrap"

eng, err := sloptrap.NewStaticEngine(sloptrap.StaticConfig{
    Site:            sloptrap.SitePinterest, // "youtube", "tiktok", "pinterest", or custom
    BuiltinVerified: true,                   // or BundlesFS: embeddedRulesFS / BundlesDir: "./rules"
    VerifiedOnly:    true,                   // enforce Official or Source-Attested rules only
})
verdict, err := eng.Evaluate(ctx, fingerprint)
// verdict.Action -> "allow" | "warn" | "block" (verdict.Score 0..100)
// JavaScript / Browser / Extension — sdk/sloptrap-sdk.js
import { SlopTrapStaticEngine, normalizeAccountSnapshot } from "https://sloptrap.github.io/sdk/sloptrap-sdk.js";

const engine = new SlopTrapStaticEngine({ site: "tiktok", verifiedOnly: true });
await engine.loadBundles([myBundledRuleJson]);

const fp = normalizeAccountSnapshot("tiktok", { handle: "@clipfarm-x9z", recentUploadsPerDay: 4.5 });
const verdict = await engine.evaluate(fp);

Mode B — Full functionality with drop-in UI sections

When your application exposes user settings, pair ManagedClient / SlopTrapClient with SlopTrap's prebuilt UI components for Web/Extension views, Go HTTP/WebView apps, or Bubble Tea TUIs: 

<!-- Web / Browser Extension / Electron: 2-line Gravity UI Web Component -->
<script type="module" src="https://sloptrap.github.io/sdk/sloptrap-ui.js"></script>
<sloptrap-rules-panel site="youtube" verified-only></sloptrap-rules-panel>
// Go — Mountable Web UI section (Wails / WebView / Admin HTTP) OR Bubble Tea TUI panel
client, _ := sloptrap.NewManagedClient(sloptrap.ManagedConfig{
    Site:            "youtube",
    StorageDir:      "~/.config/myapp/sloptrap",
    VerifiedOnly:    true,
    FallbackBuiltin: true,
})

// Option 1: Mount prebuilt Gravity UI settings section on any net/http router
mux.Handle("/sloptrap/", http.StripPrefix("/sloptrap", sloptrapui.NewWebSectionHandler(client)))

// Option 2: Embed Bubble Tea TUI sub-model inside an existing terminal app
rulesTab := sloptrapui.NewRulesPanel(client)

2. Pluggable target site adapters

SlopTrap decouples site scraping/DOM extraction from rule evaluation via PlatformAdapter. Built-in adapters ship for YouTube (youtube), TikTok (tiktok), and Pinterest (pinterest), and custom platforms register in one call: 

// Go — Register a custom target platform adapter
sloptrap.RegisterAdapter(sloptrap.NewAdapter(
    "bluesky",
    "Bluesky",
    func(target string) bool { return strings.Contains(target, "bsky.app/") },
    func(ctx context.Context, target string) (sloptrap.Fingerprint, error) {
        snap := fetchBlueskyActor(ctx, target)
        return sloptrap.NormalizeAccountSnapshot("bluesky", snap), nil
    },
))
Cross-site signal reuse: Because account dormancy gaps, post velocity, handle-stem clones, LLM/keyword-stuffed captions, TTS prosody, synthetic image ratios, and outbound link rings map into the same normalized Fingerprint schema, rule authors use identical tooling across video, short-form, and image platforms.

3. Standalone CLI & daemon setup

  • Go 1.24+ — Pure-Go SQLite (modernc.org/sqlite) and pure-Go WebAssembly runtime (wazero); no CGO required.
  • Optional — ffmpeg: Enables 45-second EBU R128 loudness range (LRA) and -65dBFS digital dead-air acoustic TTS probing (a in TUI or --audio on CLI).
  • Optional — Community blocklists: Auto-detects local AiSList checkouts (or --aislist /path) for offline stem-sibling matching.
git clone git@github.com:sloptrap/sloptrap.git
cd sloptrap
go build -o sloptrap ./cmd/sloptrap

# Build & audit all site-specific .strule leaderboards
./sloptrap rules build-defaults --out ../sloptrap-site
./sloptrap rules audit ../sloptrap-site/bundles

4. Terminal UI guide

Running ./sloptrap launches the interactive Bubble Tea workspace. Pass --listen 0.0.0.0:8787 to serve the HTTP verification API alongside the TUI.

Input Action
↑ / ↓, j / k Move selection in queue or scroll Forensic Inspector when right pane is focused.
← / →, Tab Switch focus between queue and Inspector tabs ([ / ] cycle tabs directly).
1 .. 5 Select tab: 1:Overview, 2:Timeline, 3:Script & Voice, 4:Report, 5:WASM Rules.
s / d / C Scan target URL/handle (s), open Niche Discovery (d), or toggle Continuous Crawl (C).
w / e / A Toggle local whitelist (w), export plain-text lists (e), or toggle Anonymous rule rankings (A).

5. HTTP server API reference (--serve / --listen)

Endpoint Description
GET /api/v1/health Returns service status and local SQLite scan/block/warn/whitelist counts.
POST /api/v1/check Batched account/item verification with singleflight live scanning when scan_unknown: true.
POST /api/v1/whitelist Marks or unmarks an account as whitelisted in SQLite.
GET /lists/blocklist.txt
GET /lists/warnlist.txt		 Plain-text blocklist and warnlist feeds for media clients and browser extensions.
