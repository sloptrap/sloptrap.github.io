1. Rule Definition Studio (sloptrap)

The core sloptrap/sloptrap repository provides the Svelte 5 + Tauri v2 Rule Definition Studio, which runs either directly in the browser (launch hosted Studio) or as a native desktop app:

  • Known Slop & Known-Good Channel Sets (AiSList & Extension): Load specified lists of Known Slop and Known Good channels/accounts (import channels flagged directly in sloptrap-extension, load YouTube slop channels from Override92/AiSList, or paste @handles/URLs) to measure live rule effectiveness (Recall, Known Good Safe %, False Positives, and F1) against their content.
  • One-Click Publish → Cloudflare Worker Deduplication → GitHub Signing: Clicking Publish to Leaderboard sends the rule definition to the Cloudflare Worker (POST /api/v1/rules/publish), which compares its rename-invariant canonical AST against existing rules and, when no match exists, dispatches it to GitHub Actions (compile-submitted-rule.yml) to be compiled from source and signed as a Verified · Source .strule bundle.
  • Common Cross-Site Rule Syntax: Switch freely between the clean sentence-style Visual Builder and a readable cross-site DSL sharing signals such as post.frequency, account.dormancy_days, post.title_reuse, text.formal_prose, voice.pacing_variance, and media.synthetic_ratio.
  • Shared Variables & Threshold Actions: Rules can add or set values on shared variables (e.g. suspicion, script_risk, voice_risk) accumulated across multiple rules and checked against thresholds (block, hide, dim, warn).
  • Token Sliders & .strule Export: Tune $token sliders with live microsecond WebAssembly recompilation, verify the 4-layer capability and anti-poisoning security audit, and export Ed25519-signed .strule bundles.
# Example Common Cross-Site Syntax
token high_post_rate = 0.9
token block_cutoff   = 60
var suspicion = 0

rule "High daily post frequency"
  when post.frequency >= $high_post_rate ramp 1.5
  then add 36 to suspicion

decide "Block high-suspicion accounts"
  when suspicion >= $block_cutoff
  then block

cd sloptrap

# Run in a browser
npm run dev

# Or run as a desktop application (Tauri v2 + Rust live URL extractor)
npm run tauri dev

2. Library & Drop-in UI Integration

Applications can embed SlopTrap either as a headless static rule evaluator or with prebuilt UI sections for full rule management.

Mode A — Static rule set (headless, zero network)

// JavaScript / Browser / Extension — sdk/sloptrap-sdk.js
import { SlopTrapStaticEngine, normalizeAccountSnapshot } from "https://sloptrap.github.io/sdk/sloptrap-sdk.js";

const engine = new SlopTrapStaticEngine({ site: "pinterest", verifiedOnly: true });
await engine.loadBundles([myStaticStruleJson]);

const fp = normalizeAccountSnapshot("pinterest", { handle: "@decor-mill-z4k", recentUploadsPerDay: 12 });
const verdict = await engine.evaluate(fp); // { score, action: "allow" | "warn" | "block" }
// Go — pkg/sloptrap (in sloptrap/sloptrap-tube-tui)
eng, err := sloptrap.NewStaticEngine(sloptrap.StaticConfig{
    Site:            sloptrap.SitePinterest,
    BuiltinVerified: true, // or BundlesFS: embeddedRulesFS / BundlesDir: "./rules"
    VerifiedOnly:    true,
})
verdict, err := eng.Evaluate(ctx, fingerprint)

Mode B — Drop-in UI sections for full functionality

<!-- Web / Browser Extension / Electron: Gravity UI Web Component -->
<script type="module" src="https://sloptrap.github.io/sdk/sloptrap-ui.js"></script>
<sloptrap-rules-panel site="youtube" verified-only></sloptrap-rules-panel>

3. Pluggable Target Site Adapters

Site adapters decouple platform DOM/API extraction from .strule WebAssembly execution. Built-in adapters cover youtube, tiktok, and pinterest, while custom platforms register in one call: 

import { registerSiteAdapter, normalizeAccountSnapshot } from "https://sloptrap.github.io/sdk/sloptrap-sdk.js";

registerSiteAdapter({
  siteId: "bluesky",
  displayName: "Bluesky",
  matchUrl: url => /bsky\.app/i.test(url),
  extract: actorData => normalizeAccountSnapshot("bluesky", actorData),
});

4. Example Applications

  • sloptrap/sloptrap-tube-tui (Example YouTube Forensic TUI & Server): Reference Go terminal application combining YouTube upload-history dormancy analysis, json3 caption prosody, optional 45-second ffmpeg EBU R128 dead-air probing, autonomous crawling, and local HTTP verification APIs with SlopTrap's .strule WebAssembly runtime.
  • sloptrap/sloptrap-extension (Chromium & Firefox Extension): Single-monorepo Manifest V3 extension filtering YouTube, TikTok, and Pinterest feeds in real time using static and registry-synced Verified .strule bundles.

cd sloptrap-tube-tui
go build -o sloptrap-tube-tui ./cmd/sloptrap
./sloptrap-tube-tui --listen 0.0.0.0:8787
