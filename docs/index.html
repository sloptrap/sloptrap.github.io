SlopTrap Documentation

Complete guide to installing, running, and integrating SlopTrap across the interactive terminal TUI, autonomous mass-crawler, WASM rule engine, and HTTP verification daemon.

1. Installation & Prerequisites

  • Go 1.24+ (pure-Go SQLite via modernc.org/sqlite and pure-Go WASM interpreter via wazero — no CGO required).
  • Optional — ffmpeg: Enables 45-second EBU R128 loudness range (LRA) and -65dBFS digital dead-air acoustic TTS probing (a in TUI or --audio on CLI).
  • Optional — mpv & gh: Instant playback of newest/oldest channel uploads (o / O) and formatted GitHub issue submission to Override92/AiSList.
  • Optional — Local AiSList Checkout: Auto-detected at ./AiSList or ../AiSList (or passed via --aislist /path/to/AiSList) for instant cross-checking and stem-sibling matching against 70,000+ community entries.
git clone git@github.com:sloptrap/sloptrap.git
cd sloptrap
go build -o sloptrap ./cmd/sloptrap

# Verify binary & flags
./sloptrap -h
Local Data Paths: Scanned channel reports and review/whitelist states are stored automatically in ~/.local/share/sloptrap/sloptrap.db (override with --db). Local WASM rule bundles are loaded from ~/.local/share/sloptrap/rules/*.strule (as well as ../sloptrap-site/bundles when present).

2. Interactive TUI Guide

Running ./sloptrap with no flags launches the interactive Bubble Tea workspace. Pass --listen 0.0.0.0:8787 to run the live HTTP API server alongside the TUI and inspect incoming client scans in real time. 

# Launch TUI standalone
./sloptrap

# Launch TUI + HTTP API server on port 8787 + initial targets
./sloptrap --listen 0.0.0.0:8787 "@UntoldTruths-x8z,@3blue1brown"

3. Headless CLI & Autonomous Crawler Modes

# Headless forensic scan (human-readable report on stdout)
./sloptrap --headless --scan "@bygonephilosophy,@veritasium"

# Headless scan with 45s ffmpeg audio analysis + full JSON output
./sloptrap --headless --audio --json --scan "https://www.youtube.com/watch?v=dQw4w9WgXcQ"

# Mass-crawl 500 unlisted channels across slop niches and export AiSList-format lists
./sloptrap --crawl 500 --export ./exports

# Export existing SQLite database detections without scanning
./sloptrap --export ./exports

4. AiSList Auto-Reporting & Submission Identity

Every newly blocked high-confidence slop channel not yet listed in AiSList can be automatically reported to POST https://api.aisloplist.com with configurable identity options:

  • Anonymous (--report-as=anonymous) — Submits "username": "Anonymous" with zero account association.
  • Custom Username (--report-as=custom --username=...) — Credits reports to an explicit username or handle.
  • Client Account Callback (--report-as=youtube) — Queries a connected media client's GET /api/v1/account callback endpoint to resolve the active signed-in YouTube account name dynamically at report time (falling back safely to Anonymous if signed out or unreachable).

5. HTTP Server API Reference (--serve / --listen)

Method & Path Description
GET /api/v1/health Returns JSON health status, local SQLite scan/block/warn/whitelist counts, and loaded AiSList counts.
POST /api/v1/check Batched channel/video verification. Checks AiSList + SQLite cache immediately and launches singleflight-deduplicated live scans when scan_unknown: true.
POST /api/v1/whitelist Marks or unmarks a channel as whitelisted in SQLite.
GET /lists/blocklist.txt
GET /lists/warnlist.txt		 Exports dynamically updated AiSList-formatted plain-text channel lists.
GET /lists/leaderboard.json
GET /lists/bundles/<id>.strule		 Local LAN mirror of leaderboard metadata and signed .strule WASM bundles.
