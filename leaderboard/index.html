Community rules are not reviewed by maintainers. They are anonymous submissions that the private pipeline compiled from source, checked (static WASM audit, sandboxed execution and a hidden-holdout false-positive ceiling) and signed with the community key. Clients keep them disabled unless you turn on the "Community rules" setting, and verified-only mode never loads them.
Trust tiers: the tier is computed from the bundle's signing key, never from fields inside the bundle or the feed. Official rules are signed offline by a SlopTrap maintainer with the pinned key 0540a396… and are the only rules shown as verified. Community rules (ids start with community-) are signed by the automated community pipeline key 34c3c2ee…. Bundles signed by any other key are never listed. Every listed .strule passes the sloptrap-bundle-v2 signature check, the static WASM audit and a fuel-metered sandbox run on every sync.
