SlopTrap Privacy Policy

Last updated: November 27, 2026 · Applies to the SlopTrap Browser Extension (Chrome / Chromium & Firefox), SlopTrap Rule Studio, and SlopTrap TUI.

SlopTrap is a free, open-source content filter designed to evaluate feed items locally on your device without tracking your browsing activity.

1. Default Operation — Zero Personal Data Collection

Out of the box, SlopTrap operates locally inside your browser with all optional contribution features disabled:

  • Local Sandboxed Evaluation: Feed card metadata on YouTube, TikTok, and Pinterest is evaluated locally inside a zero-import, fuel-metered WebAssembly (.strule) sandbox and against locally cached channel lists.
  • No Browsing or Watch History Collected: SlopTrap never collects, logs, or transmits the pages you visit, videos or pins you view, search terms, personal profile details, or browser cookies.
  • Credential-Free Static Sync: Official rule bundles (bundles/*.strule), Ed25519-signed pre-matched rule lists (lists/<site>/<rule_id>.txt), and enabled external community lists (such as AiSList) are fetched over HTTPS with cookies omitted (credentials: "omit").
  • Local Storage Only: Your filter preferences, rule toggles, 1-click channel whitelist overrides, and channels queued via the right-click menu for testing in Rule Studio remain in your browser's local extension storage.

2. Strictly Opt-In Features

  • Anonymous Rule Rankings (Optional): When enabled, periodic rule update checks include a randomly generated local installation UUID so the public leaderboard can count active installs per rule over a rolling 30-day window. No user identity, account information, or browsing history is attached, and stale install rows expire automatically.
  • Contributor Sign-In & Public Rule List Reporting (Off by Default): If you explicitly choose to sign in via Google, GitHub, or Discord and enable "Share new matches to lists" (and grant Firefox's optional data collection consent prompt on Firefox):
    • Zero PII Stored: SlopTrap verifies account age/verification status during OAuth callback solely to prevent automated Sybil abuse, computes a one-way keyed HMAC-SHA256 digest of your provider subject ID, and immediately discards the OAuth response. SlopTrap never stores your email address, username, display name, avatar, or OAuth provider access token.
    • Keyed Abuse-Prevention Hashes: Rate-limiting and quorum diversity checks use one-way HMAC-hashed network subnet/ASN identifiers rather than raw client IP addresses.
    • Minimal Match Payload: Only public channel identifiers (@handle or YouTube UC... channel ID) that triggered a verified blocking rule ({site, rule_id, rule_version, account_key}) are submitted, deduplicated to at most one vote per contributor per channel and rule.
    • Logout & Cascading Revocation: Clicking Logout revokes your contributor bearer token immediately and clears it from your local IndexedDB vault. Revoking an account cascades to remove its votes from public list counts.
  • Optional GitHub Personal Access Token: If you manually paste a GitHub token in Settings to automate external blocklist issue creation (e.g., AiSList), that token is stored solely in your local IndexedDB vault and transmitted only directly to https://api.github.com when you submit a report.
  • Optional Local Companion Daemon: Connecting to http://127.0.0.1 / http://localhost occurs only if you explicitly configure a local sloptrap TUI daemon URL on your own machine.

3. Data Sharing & Chrome Web Store Limited Use Disclosure

  • SlopTrap never sells, rents, or transfers user data to third parties, advertisers, or data brokers.
  • SlopTrap does not use or transfer data for personalized advertising, profiling, creditworthiness, or any purpose unrelated to filtering synthetic/low-effort content feeds.
  • SlopTrap's use and transfer of any information received from Google APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

4. Support, Data Deletion & Contact

  • Clear Local Data: Disable toggles, click Logout in SlopTrap Settings, or uninstall the extension to erase all locally stored extension state and tokens immediately.
  • Documentation & Troubleshooting: Visit the SlopTrap Documentation & SDK Guide and the Bundle v2 & WASM Sandbox Specification.
  • Bug Reports & Support: Open an issue or contact the SlopTrap maintainers via github.com/sloptrap (including public registry issues on sloptrap/sloptrap.github.io).
